# PROYECTO-LOGICA-CONSULTAS-DE-SQL

📄 Descripción del proyecto

Este proyecto reúne todas las consultas desarrolladas durante el módulo SQL, resolviendo cada uno de los ejercicios planteados en el documento EnunciadoDataProject_SQL.Lógica.
Cada consulta incluye:
- Su script SQL correspondiente
- Comentarios explicativos que describen los pasos lógicos seguidos
- La estructura necesaria para obtener los datos solicitados desde la base de datos.
Todo el contenido se encuentra organizado dentro de la carpeta Proyecto_SQL.

🎯 Objetivo del ejercicio

El objetivo principal es demostrar la capacidad de:
- Realizar consultas SQL correctamente.
- Combinar funciones, joins y subconsultas para obtener los resultados requeridos en cada enunciado.
- Aplicar buenas prácticas de estructuración y documentación de consultas.

🛠️ Conocimientos aplicados: Instalación y configuración de la BBDD en DBeaver

1. Importación de la base de datos desde el archivo SQL BBDD_Proyecto_shakila_sinuser.
2. Copia y guardado del contenido SQL en un nuevo script en mi equipo local (Postgres → Nuevo Script SQL → pegar contenido).
3. Guardado del script SQL desde el menú Archivo.
4. Creación de una nueva base de datos (clic derecho → Crear Nueva Base de Datos).
5. Establecer la nueva base de datos como predeterminada.
6. Importación del archivo SQL desde el menú Archivo → Importar.
7. Selección del motor Postgres en el panel superior.
8. Ejecución del script completo mediante el botón Ejecutar Comando SQL.
9. Actualización de la carpeta de la nueva BBDD (clic derecho → Renovar) para generar las tablas.
10. Visualización del diagrama mediante public → clic derecho → View Diagram.
11. Vinculación del esquema en la sección Diagrams del panel inferior izquierdo.

📚 Conocimientos aplicados en las consultas SQL

1. Funciones de agregación:  
   SUM, COUNT, CONCAT, MIN, MAX, AVG, STDDEV, VARIANCE.

2. Funciones de agrupación:  
   ORDER BY, GROUP BY, HAVING, LIMIT, OFFSET.

3. Relaciones entre tablas mediante JOIN:  
   INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL JOIN, CROSS JOIN.

4. Uso de subconsultas para resolver consultas anidadas.

5. Creación de vistas mediante CREATE VIEW.

6. Consultas con CTE (Common Table Expressions) usando WITH.

7. Documentación mediante comentarios explicando cada paso en consultas complejas.
